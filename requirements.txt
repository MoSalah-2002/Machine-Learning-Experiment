## 🚀 Quick start

```bash
git clone https://github.com/MoSalah-2002/Machine-Learning-Experiment.git
cd Machine-Learning-Experiment
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
```

Launch a notebook using Jupyter or Google Colab. Notebooks may require external CSV/PKL datasets; dataset files are intentionally not bundled, so update the paths to your local copies.

## 🔐 Security

Hard-coded credentials detected during preparation were removed from the published notebook copies. Use environment variables for any service credentials and do not commit API keys, tokens, or private datasets.

## 📝 Disclaimer

These notebooks are independent learning experiments. They are not all benchmarked or production-ready, and their performance should not be interpreted as a validated model comparison.
