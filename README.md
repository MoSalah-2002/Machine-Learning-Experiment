## 🚀 Getting started

```bash
git clone https://github.com/MoSalah-2002/Machine-Learning-Experiment.git
cd Machine-Learning-Experiment
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
jupyter notebook
```

Some notebooks require external CSV or PKL datasets. Download the relevant data separately and update the file paths before running.

## 🔎 Methodology notes

Treat these notebooks as independent experiments and learning artifacts, not as a unified benchmark. Check train/test separation, preprocessing, and evaluation methodology before interpreting reported scores. Not every notebook has been run end-to-end in a clean environment.

## 🔐 Security

Credentials detected in the source material were removed from prepared copies where applicable. Keep API keys and private data outside Git and use environment variables for secrets.
